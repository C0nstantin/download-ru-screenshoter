# DownloadRu Screenshoter

Десктопное приложение для создания скриншотов и записи видео с экрана с автоматической загрузкой на [download.ru](https://download.ru).

Работает в трее — без открытых окон не занимает место в Dock и Cmd+Tab.

## Возможности

### Скриншоты

- **Скриншот области** — выделение произвольной прямоугольной области экрана с overlay-интерфейсом
- **Скриншот всего экрана** — мгновенный захват всего экрана
- **Скриншот окна** — захват конкретного окна (macOS: нативный пикер)
- **Мульти-монитор** — overlay корректно растягивается на все подключённые дисплеи (macOS)

### Редактор скриншотов

После создания скриншота открывается встроенный редактор с инструментами аннотации:

- **Стрелки** — рисование стрелок-указателей
- **Прямоугольники** — выделение областей рамкой
- **Текст** — добавление текстовых надписей
- **Свободное рисование** — рисование кистью от руки
- **Размытие (Blur)** — замазывание конфиденциальной информации
- **Обрезка (Crop)** — обрезка скриншота до нужного размера
- Выбор цвета и толщины линий
- Отмена/повтор действий (Undo/Redo)
- Перетаскивание и изменение размера аннотаций

### Запись видео (macOS)

Три режима записи видео с экрана:

- **Запись экрана** — запись всего экрана через нативный macOS пикер (аналог Cmd+Shift+5)
- **Запись области** — overlay для выбора прямоугольной области, затем запись выбранного участка
- **Запись окна** — выбор конкретного окна из списка, запись только этого окна

Во время записи:

- Индикатор записи с пульсирующей красной точкой в углу экрана
- **Кнопка мьюта микрофона** — можно отключить/включить микрофон прямо во время записи
- Кнопка "Стоп" для остановки записи
- Аудио с микрофона записывается по умолчанию

После записи открывается окно результата:

- **Превью видео** с плеером
- **Обрезка (Trim)** — выбор начала и конца фрагмента ползунками
- **Конвертация в MP4** — три пресета качества:
  - Высокое (оригинальное разрешение)
  - Среднее (1080p)
  - Низкое (720p)
- **Загрузка на download.ru** — загрузка видео и копирование ссылки в буфер обмена
- **Сохранение** — сохранение файла локально через диалог выбора папки
- **Удаление** — удаление записи

> Запись видео на Linux и Windows пока не реализована (TODO).

### Загрузка на download.ru

- Авторизация через OAuth 2.0 (download.ru)
- Автоматическая загрузка скриншотов после сохранения в редакторе
- Загрузка видео из окна результата
- Ссылка автоматически копируется в буфер обмена
- Системное уведомление после успешной загрузки
- Автоматическая переавторизация при истечении токена
- Файлы загружаются в папку `Screenshots` на download.ru

### Настраиваемые горячие клавиши

| Действие | Хоткей по умолчанию |
|---|---|
| Скриншот области | `Ctrl+Shift+4` |
| Скриншот экрана | `Ctrl+Shift+3` |
| Скриншот окна | `Ctrl+Shift+Alt+3` |

Горячие клавиши можно переназначить в настройках.

### Поведение приложения

- Живёт в системном трее (иконка в панели меню)
- Двойной клик на иконку в трее — открывает настройки
- Без открытых окон скрывается из Dock и Cmd+Tab (macOS)
- При открытии любого окна появляется в Dock и Cmd+Tab
- Все действия доступны через контекстное меню трея

## Установка

### macOS

1. Скачай `.dmg` из [Releases](../../releases)
2. Перетащи приложение в `/Applications`
3. Сними карантин (приложение не подписано Apple-сертификатом):
   ```bash
   xattr -cr /Applications/DownloadRu\ Screenshoter.app
   ```
   Или: правый клик → "Открыть" → подтвердить в диалоге
4. Выдай разрешение на запись экрана: **Системные настройки → Конфиденциальность → Запись экрана**
5. Для записи аудио: выдай разрешение на микрофон

### Windows

1. Скачай `.exe` установщик из [Releases](../../releases)
2. Запусти установщик
3. При запросе UAC — подтверди установку

### Linux

1. Скачай `.AppImage` или `.deb` из [Releases](../../releases)
2. AppImage: `chmod +x DownloadRu-Screenshoter.AppImage && ./DownloadRu-Screenshoter.AppImage`
3. deb: `sudo dpkg -i downloadru-screenshoter.deb`

**Системные зависимости** (Ubuntu/Debian):

```bash
sudo apt install -y \
  libwebkit2gtk-4.1-dev \
  libgtk-3-dev \
  libayatana-appindicator3-dev \
  librsvg2-dev \
  libssl-dev \
  libxcb-composite0-dev \
  libx11-dev \
  xdotool
```

Fedora/RHEL:

```bash
sudo dnf install -y \
  webkit2gtk4.1-devel \
  gtk3-devel \
  libayatana-appindicator-gtk3-devel \
  librsvg2-devel \
  openssl-devel \
  libxcb-devel \
  xdotool
```

## Быстрый старт

1. Запусти приложение — иконка появится в трее
2. Открой настройки (двойной клик по иконке или через меню трея)
3. Нажми **"Войти через download.ru"** — авторизуйся
4. Делай скриншоты горячими клавишами или через меню трея
5. Редактируй в открывшемся редакторе → нажми "Загрузить"
6. Ссылка скопируется в буфер обмена автоматически

## Разработка

### Требования

- [Node.js](https://nodejs.org/) 18+
- [Rust](https://rustup.rs/) 1.70+
- [Tauri CLI](https://tauri.app/start/prerequisites/)

На macOS дополнительно: Xcode Command Line Tools (`xcode-select --install`)

На Linux дополнительно: системные зависимости из раздела установки выше

### Запуск

```bash
npm install
npm run tauri dev
```

### Сборка

```bash
npm run tauri build
```

Собранные файлы появятся в `src-tauri/target/release/bundle/`.

### Структура проекта

```
src/                          # React фронтенд
├── pages/
│   ├── OverlayPage.tsx       # Overlay для выбора области (скриншот/видео)
│   ├── EditorPage.tsx        # Редактор скриншотов с аннотациями
│   ├── RecordingPage.tsx     # Индикатор записи (Стоп + Мьют)
│   ├── VideoResultPage.tsx   # Результат видеозаписи (превью, обрезка, конвертация)
│   └── SettingsPage.tsx      # Настройки (авторизация, горячие клавиши)
├── App.tsx                   # Роутинг
└── store/                    # Zustand store для редактора

src-tauri/src/                # Rust бэкенд
├── lib.rs                    # Точка входа, трей, обработчики меню, localfile:// протокол
├── state.rs                  # Глобальное состояние приложения (AppState)
└── commands/
    ├── screenshot.rs         # Захват экрана, overlay, мульти-монитор
    ├── recording.rs          # Запись видео, конвертация, мьют микрофона
    ├── upload.rs             # OAuth авторизация, загрузка на download.ru
    ├── hotkeys.rs            # Глобальные горячие клавиши
    └── settings.rs           # Системные настройки
```
