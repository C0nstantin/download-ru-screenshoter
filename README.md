# Download Screenshoter

Приложение для создания скриншотов с редактированием и автоматической загрузкой на download.ru

## Горячие клавиши

- `Ctrl+Shift+4` — скриншот области (с выделением)
- `Ctrl+Shift+3` — скриншот всего экрана

## Функции

- Выделение области экрана
- Редактирование скриншота (стрелки, рамки, текст, размытие)
- Автоматическая загрузка на download.ru
- Копирование ссылки в буфер обмена

## Требования к иконке для трея (macOS)

### Технические требования

| Параметр | Значение |
|----------|----------|
| Формат | PNG с прозрачным фоном (alpha channel) |
| Размеры | 16x16 px (1x), 32x32 px (2x Retina), 64x64 px (опционально) |
| Цветовая модель | RGBA |
| Стиль | Template image — монохромный чёрный (#000000) |

### Рекомендации по дизайну

1. **Простота** — иконка должна быть узнаваема в размере 16x16 px
2. **Монохромность** — использовать только чёрный цвет (#000000), macOS сам инвертирует для тёмной темы
3. **Padding** — оставить 1-2 px отступа по краям
4. **Без градиентов** — только сплошной цвет
5. **Чёткие линии** — толщина линий не менее 1 px

### Концепция иконки

**Вариант 1: Облако + стрелка вниз (download)**
```
     ╭───────╮
   ╭─┤       ├─╮
  │             │
  │      ↓      │
  ╰─────────────╯
```

**Вариант 2: Облако + рамка скриншота**
```
     ╭───────╮
   ╭─┤       ├─╮
  │   ┌─────┐   │
  │   │     │   │
  ╰───┴─────┴───╯
```

**Вариант 3: Камера/скриншот в облаке**
```
     ╭───────╮
   ╭─┤   ◉   ├─╮
  │   ╭─────╮   │
  │   ╰─────╯   │
  ╰─────────────╯
```

### Текущая проблема

Текущая иконка (download.svg) многоцветная:
- Облако — голубое (#75A4D5)
- Шестерёнки — оливковые (#A4A743)

Многоцветная иконка не работает как template image в macOS — отображается белым квадратом.

### Что нужно от дизайнера

1. **Монохромная иконка** для трея macOS (template image)
   - Размер: 32x32 px (будет уменьшена до 16x16)
   - Цвет: чёрный (#000000) на прозрачном фоне
   - Формат: PNG или SVG

2. **Цветная иконка** для приложения (Dock, Windows taskbar)
   - Размер: 1024x1024 px
   - Может быть многоцветной
   - Формат: PNG на прозрачном фоне

### Файлы для замены после получения иконок

```
src-tauri/icons/
├── 32x32.png          # для трея
├── 128x128.png        # для приложения
├── 128x128@2x.png     # для Retina
├── icon.icns          # macOS app bundle
└── icon.ico           # Windows
```

### Команды для генерации icns из PNG 1024x1024

```bash
mkdir icon.iconset
sips -z 16 16 icon_1024.png --out icon.iconset/icon_16x16.png
sips -z 32 32 icon_1024.png --out icon.iconset/icon_16x16@2x.png
sips -z 32 32 icon_1024.png --out icon.iconset/icon_32x32.png
sips -z 64 64 icon_1024.png --out icon.iconset/icon_32x32@2x.png
sips -z 128 128 icon_1024.png --out icon.iconset/icon_128x128.png
sips -z 256 256 icon_1024.png --out icon.iconset/icon_128x128@2x.png
sips -z 256 256 icon_1024.png --out icon.iconset/icon_256x256.png
sips -z 512 512 icon_1024.png --out icon.iconset/icon_256x256@2x.png
sips -z 512 512 icon_1024.png --out icon.iconset/icon_512x512.png
sips -z 1024 1024 icon_1024.png --out icon.iconset/icon_512x512@2x.png
iconutil -c icns icon.iconset -o icon.icns
rm -rf icon.iconset
```
